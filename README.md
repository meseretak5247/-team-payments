# Team Payments App\n\nSimple web application to track monthly payments to team members, with checklist items and reports.\nStack: Node.js, Express, Sequelize, SQLite, EJS.\n\nQuick start\n1. Clone your repository and checkout the feature branch (example):\n   git fetch origin\n   git checkout feature/team-payments-app\n\n2. Copy .env example:\n   cp .env.example .env\n\n3. Install:\n   npm install\n\n4. Seed sample data (creates 20 members and one payment each):\n   npm run seed\n\n5. Start:\n   npm start\n\n6. Open http://localhost:3000\n\nWhat it provides\n- Dashboard with current month totals (due/paid)\n- Members list: add members, toggle active\n- Payments: create payments, mark as paid/unpaid\n- Checklist per payment: toggle checklist items\n- Reports page with per-member totals and CSV download\n\nHow to add these files to your existing repo locally and push to the branch:\n1. Ensure you are on the feature branch:\n   git checkout feature/team-payments-app\n\n2. Copy the provided files into the repository root (create folders models, views, public, data).\n   - models/*.js\n   - views/*.ejs\n   - public/styles.css\n   - server.js, seed.js, package.json, .env.example, README.md\n\n3. Commit and push:\n   git add .\n   git commit -m "Add team payments app (Express + SQLite)"\n   git push origin feature/team-payments-app\n\nNotes & next steps\n- This sample app intentionally keeps auth out to be simple. For production, add authentication and access controls.\n- You can switch SQLite to Postgres/MySQL by reconfiguring Sequelize in models/index.js and environment variables.\n- If you want, I can open a PR with these files added to the repository branch (I can prepare the commits and push them for you).
